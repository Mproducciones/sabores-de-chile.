# Sabores de Chile

PWA responsive para restaurantes: carta digital, pedidos QR y panel operativo. Esta primera entrega es una base funcional de frontend; caja, inventario, usuarios y pedidos persistentes requieren backend y autenticación antes de uso comercial.

## Desarrollo

- Node.js 20+
- `npm install`
- `npm run dev`
- `npm run build`

## Despliegue en Vercel

Importar este repositorio en Vercel. Framework: Vite; Build command: `npm run build`; Output directory: `dist`.
